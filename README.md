# Amul Shop - Draft Version

A draft/experimental version of the Shree Laxmi Amul Shopiee website. This is a prototype implementation showcasing design concepts and features for an authorized Amul outlet.

## Features

- **Responsive Design**: Modern HTML/CSS layout that works on all devices
- **Product Showcase**: Display of Amul products offered at the store
- **Gallery**: Visual tour of the store and products
- **About Section**: Information about the store and services
- **Contact Form**: Easy way for customers to get in touch

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive design principles

## Project Structure

```
Amul-Shop-Daft/
 index.html
 about.html
 products.html
 gallery.html
 contact.html
 style.css
 images/
 Amul.jpg
```

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/omspradippatil/Amul-Shop-Daft.git
   ```

2. Open `index.html` in your web browser to view the website

## Local Development

No build process required. Simply edit the HTML, CSS, or JavaScript files and refresh your browser.
